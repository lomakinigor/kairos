# Kairos 1.2.9 — проверка автозапуска

Затронуты автоматическая установка обновления при запуске Windows и размер зелёного индикатора. Внешний вид остальной части приложения не меняется.

| Принцип | Оценка | Основание |
| --- | --- | --- |
| Дизайн | 79% | Кружок оплаты в 2,5 раза крупнее и различим при трёх масштабах; виджет не расширяется по ширине. |
| Удобство | 82% | При автозапуске скачанное обновление применяется без кнопки, если не открыто рабочее окно; при ручном запуске остаётся прежний диалог. |
| Выгода | 81% | Компьютер автоматически переходит к новому опубликованному Kairos после загрузки обновления; при отсутствии сети остаётся рабочая установленная версия. |

Пороги 70/80/75 пройдены. Ограничение: до проверки сети и завершения скачивания на экране может находиться предыдущая версия. Данные других компьютеров для проверки недоступны.
