# UX-аудит Kairos 1.2.0 — owner analytics

Дата: 2026-08-04

## Итоговый скор

| Принцип | Результат | Порог | Статус |
|---|---:|---:|---|
| Дизайн | 88% | 70% | ✅ |
| Удобство | 93% | 80% | ✅ |
| Выгода | 93% | 75% | ✅ |

Вердикт: **ГОТОВО К РЕЛИЗУ**.

## Дизайн — 21/24

- Иерархия 3/3: total доминирует, периоды и версии вторичны.
- Соответствие Kairos 3/3: графитовый фон, янтарный accent, моноширинные числа.
- Контраст и состояния 3/3.
- Spacing и сетка 3/3.
- Loading/error/empty states 3/3.
- Типографика 2/3: Segoe UI надёжен офлайн, но не уникален.
- Доступность 2/3: semantic labels и focus-visible есть; нужен screen-reader smoke test.
- Render fidelity 2/3: code-based проверка без ручного screenshot 125–200% scaling.

## Удобство — 28/30

- Пункт меню виден только владельцу.
- Данные обновляются автоматически и вручную одной кнопкой.
- Пять метрик читаются без настройки фильтров.
- Versions показаны компактными bars.
- Ошибки backend не затрагивают основной виджет.
- Снижение: нет выбора произвольного периода дат.

## Выгода — 25/27

- Уникальные установки отделены от GitHub downloads.
- Видны new/active и распределение версий.
- Данные подтверждены production-запросом.
- Raw ID, IP и hardware ID не возвращаются владельцу.
- Снижение: удаление userData может создать повторный installation ID.

## После релиза

1. Добавить исторический график, когда накопится минимум 30 дней данных.
2. Добавить CSV export при росте числа установок.
