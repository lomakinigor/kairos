# Kairos 1.2.11 — расположение индикатора

Проверена только запрошенная правка виджета. Статус и переход по клику сохраняются; пояснение доступно по наведению.

| Принцип | Оценка | Основание |
| --- | --- | --- |
| Дизайн | 82% | Кружок находится в свободном пространстве между циферблатами, нижняя полоса исчезла. |
| Удобство | 82% | Статус постоянно виден, по кружку можно открыть страницу; текст доступен в подсказке и для экранного доступа. |
| Выгода | 81% | Срок оплаты отслеживается без дополнительной строки, которая увеличивала виджет. |

Пороги 70/80/75 пройдены. Проверено на размерах циферблата 50, 120 и 260 пикселей с реальным масштабированием и снимком Electron.
