# Brainstorm: масштабирование, автозапуск и обновления

## 1. Пользовательская проблема

Текст виджета не полностью следует за размером циферблатов; при входе в Windows запускается старое непрозрачное окно Electron; сторонний пользователь не понимает, как получить новую версию и что в ней изменилось.

## 2. Current behavior

- Колесо мыши масштабирует Canvas, но CSS-текст остаётся почти фиксированным.
- В системе сохранился dev-автозапуск Electron, который открывает отдельное окно с логотипом Electron.
- `electron-updater` проверяет GitHub только один раз при старте через стандартное уведомление.
- Собственного окна release notes и отметки просмотренной версии нет.

## 3. Desired behavior

- Весь текст основного виджета масштабируется синхронно с циферблатами.
- При входе в Windows запускается только упакованный Kairos без окна Electron.
- Обновление скачивается в фоне, устанавливается только с согласия пользователя или при выходе.
- После первого запуска новой версии один раз показывается компактное окно «Что нового».

## 4. Ограничения

- Не увеличивать базовую площадь основного виджета и не добавлять tray/taskbar icon.
- Не терять reminders, position, timer settings и owner-token.
- Репозиторий публичный; GitHub Releases доступен внешним пользователям без токена.
- Code-signing certificate пока отсутствует.

## 5. Альтернативы

1. GitHub Releases + `electron-updater` — выбран: уже поддерживается проектом, бесплатно, репозиторий публичный.
2. Собственный update server/R2 — лишняя инфраструктура для текущего масштаба.
3. Ручное скачивание установщика — слишком неудобно и не показывает изменения автоматически.

## 6. Риски и неизвестности

- Очень старые сборки без рабочего updater потребуют однократной ручной установки.
- Windows SmartScreen может предупреждать о неподписанном установщике.
- Устаревшая запись Electron может находиться в Run key или Startup shortcut; миграция должна удалять только доказанно относящиеся к Kairos записи.
- Публикация GitHub Release является отдельным внешним действием и выполняется только после локальной проверки сборки.
