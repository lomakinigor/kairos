# Индикатор серверной подписки — brainstorming

## Проблема

Срок оплаты VDS находится в личном кабинете Weecere и его легко пропустить во время работы.

## Текущее поведение

Kairos хранит дату следующего платежа вручную в списке подписок, но не показывает её постоянно в виджете и не синхронизирует с Weecere.

## Желаемое поведение

Одна отмеченная серверная подписка показывает внизу виджета цветной статус; Kairos читает дату из отдельной локальной сессии Weecere при старте и далее раз в шесть часов.

## Ограничения

- У Weecere не обнаружен публичный API для даты оплаты.
- Вход выполняет пользователь в отдельном окне Weecere.
- Пароль, номер карты и текст кабинета не сохраняются.
- При истёкшей сессии или изменённой странице статус серый и предлагает войти снова.

## Варианты

1. Ручная дата — надёжно, но не удовлетворяет требованию автоматического чтения.
2. Расширение Chrome — требует отдельной установки и доступа к браузеру.
3. Постоянная локальная Electron-сессия Weecere — выбранный вариант: вход один раз, локальные cookies и фоновая проверка.

## Риски

Разметка Weecere может измениться. Поэтому парсер возвращает неизвестный статус вместо неверной даты.
