# Индикатор оплаты сервера

## User story

Как пользователь Kairos, я хочу постоянно видеть в виджете срок оплаты одного VDS и открыть его страницу кликом, чтобы не пропустить продление.

## Acceptance criteria

- В редакторе подписки можно указать URL Weecere и включить показ в виджете.
- Одновременно в виджете отображается только одна отслеживаемая серверная подписка.
- Вход открывается в отдельном окне с persistent Electron session; пароль не записывается приложением.
- Проверка запускается после старта приложения и раз в 6 часов.
- Дата Weecere обновляет срок подписки только после успешного распознавания.
- Формат из кабинета Weecere: метка «оплачен до», под ней дата вида «24 декабря 2026». Принимаются также прежние числовые форматы. Невалидная дата и дата из соседнего поля не меняют подписку.
- Более 7 дней: зелёный; 7–3: жёлтый; 2: красный; 1, день оплаты и просрочка: мигающий красный.
- Ошибка входа, сети или разбора: серый статус, клик открывает страницу сервера.
- Клик по индикатору открывает URL сервера в системном браузере.
- После входа в открытом окне Weecere индикатор обновляется без необходимости закрывать окно. Дата считывается только с настроенной страницы VDS.
- Фоновая проверка ждёт появления даты после загрузки страницы (включая асинхронную отрисовку), затем обновляет подписку. Если дата не появилась за ограниченное время, статус остаётся серым.
- Разбор даты учитывает, что Weecere может отдавать подписи и значения соседних колонок одной строкой с разделителем табуляции; дата должна принадлежать именно колонке «оплачен до».
- При ошибке сохраняется безопасный код причины (вход, сеть, тайм-аут, дата не найдена), который можно увидеть в подсказке индикатора. Содержимое страницы и учётные данные не сохраняются.
- Кружок статуса расположен по центру свободной области между циферблатами. Нижней полосы и видимой подписи нет; цвет, мигание и открытие страницы кликом сохраняются. Размещение не увеличивает габариты виджета.

## Изменяемые модули

- `lib/server-monitor.js` — чистые правила статуса, URL и разбор даты.
- `main.js` — session Weecere, фоновая проверка и IPC.
- `renderer/*` — индикатор и действие по клику.
- `subscriptions/*` — настройка отслеживаемого сервера.

## Rollback

Отключение флага отслеживания скрывает индикатор и прекращает обращения к Weecere; записи подписок сохраняются.
