# Обновление после входа в Weecere

Проблема: пользователь вошёл в Weecere и видит «оплачен до», а индикатор остаётся серым, пока окно входа открыто. Фоновое чтение также выполняется сразу после `did-finish-load`, до возможной отрисовки данных страницей.

Варианты: требовать закрывать окно; считывать дату из уже открытого окна; повторять отдельную фоновую загрузку. Выбран второй вариант вместе с ожиданием даты для фоновой загрузки: он даёт немедленный результат и использует уже авторизованную страницу.

Проверка: после появления даты на настроенной странице VDS статус становится `ok`, дата сохраняется и виджет получает обновление. Логин, другой URL, пустая или неверная дата не дают зелёный статус. Ожидание ограничено по времени. Пароль и содержимое страницы не записываются.

Изменения: только чтение страницы Weecere и вызов обновления в `main.js`; формат хранения подписки и IPC не меняются. Откат: вернуть прежнюю проверку после закрытия окна.
