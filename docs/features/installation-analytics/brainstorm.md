# Brainstorm: приватная статистика установок

## Пользовательская проблема

Владелец Kairos не знает, сколько сторонних установок реально запущено; GitHub показывает только скачивания.

## Current behavior

- GitHub считает загрузки release assets, но не успешные установки.
- Kairos уже создаёт случайный `installationId` для каждой установки.
- Owner-token доступен только на машине владельца.

## Desired behavior

- Каждый запуск Kairos незаметно обновляет анонимную запись установки.
- Владелец видит total/new/active и версии в отдельном окне.
- Сторонние пользователи не видят UI, уведомлений или запросов согласия.

## Ограничения

- Не сохранять IP, имя, email, hardware ID или текст пользовательских запросов.
- В базе хранить только hash случайного installation ID, timestamps и версию приложения.
- Статистика доступна только при корректном owner-token.
- Ошибка телеметрии никогда не мешает запуску приложения.

## Альтернативы

1. GitHub download count — неточно, выбран только как дополнительный ориентир.
2. Analytics Engine — удобен для событий, но retention ограничен.
3. Cloudflare D1 — выбран для уникального долговременного учёта и SQL-агрегации.

## Риски

- Удаление userData создаёт новый installation ID и будет считаться новой установкой.
- Offline-запуск попадёт в статистику только при следующем успешном запуске с интернетом.
- Без telemetry salt хеширование ID недостаточно изолировано; нужен отдельный Worker secret.
