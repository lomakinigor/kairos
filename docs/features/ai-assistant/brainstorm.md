# Kairos AI Assistant — Brainstorm

## Problem framing

Kairos должен помогать с короткими переводами RU ↔ EN и объяснять IT-термины простым русским языком, не увеличивая площадь основного виджета.

## Ответы на discovery-вопросы

1. **Проблема пользователя:** приходится переключаться в отдельный AI-чат ради коротких повседневных запросов.
2. **Текущее поведение:** Kairos показывает часы, таймер и напоминания; текстовых AI-функций нет.
3. **Желаемое поведение:** отдельное окно с вкладками «Перевод» и «IT-термин», автоматическим направлением перевода и копированием результата.
4. **Ограничения:** основной виджет не меняет размер; секрет OpenAI нельзя помещать в Electron; внешним установкам доступно 5 запросов в сутки; владелец не ограничен.
5. **Альтернативы:** локальные модели, собственный API key каждого пользователя, открытие ChatGPT в браузере, backend-прокси. Выбран backend-прокси как лучший UX при сохранении секрета.
6. **Риски:** обход анонимного device limit, недоступность сети/OpenAI, расходы при массовом использовании, утечка owner-токена, отсутствие настроенного production URL.

## Решение

- Отдельный `BrowserWindow` в существующем тёмном стиле Kairos.
- Две явные вкладки.
- Локальное определение RU/EN для подписи направления; окончательный перевод выполняет OpenAI.
- Cloudflare Worker хранит `OPENAI_API_KEY` и `OWNER_TOKEN` как secrets.
- KV-счётчик ограничивает внешние установки пятью успешными запросами в календарные сутки UTC.
- Анонимный installation ID создаётся один раз в `userData`; дополнительно Worker учитывает хеш IP, чтобы усложнить простой обход.
- Owner-токен хранится только в `userData` владельца и не включается в установщик.
