# Актуальная версия при автозапуске Windows

## Проблема

На компьютере обнаружены три записи автозапуска Kairos: установленный `Kairos.exe` дважды и Electron из проекта. Запуск установленной версии не применяет скачанное обновление без участия пользователя.

## Поведение

- Установленный Kairos регистрирует один канонический автозапуск с `--autostart` на свой `process.execPath`.
- При старте удаляются только распознанные старые записи Kairos: Electron из `projects/kairos/node_modules/electron/dist` и дублирующая запись `Kairos`, указывающая на тот же установленный exe. Чужие записи не трогаются.
- При автозапуске приложение проверяет GitHub. Когда обновление скачано и не открыты рабочие окна, оно устанавливается и перезапускает Kairos без ручного нажатия. При открытых рабочих окнах предлагает обновить обычным способом.
- Если сеть или обновление недоступны, запускается текущая установленная версия. Абсолютную гарантию последнего выпуска до запуска виджета это не даёт.
- Ручной запуск сохраняет прежний запрос на перезапуск.

## Затронутые модули и совместимость

`main.js`: автозапуск, очистка распознанных дублей, обработчик `update-downloaded`. `lib/update-policy.js`: чистые правила распознавания записей и безопасного автоматического перезапуска. Формат пользовательских данных и IPC не меняются.

## Проверка

Unit-тесты для чужих/своих записей и условий автоустановки; тесты проекта; проверка реестра и версии установленного app.asar на текущем ПК; сборка и публикация. На других ПК результат зависит от доступности GitHub и установленного Kairos.

## Откат

Предыдущая версия продолжит запускаться по канонической записи; можно вернуть прежний обработчик обновления. Удалённые дубли не нужны для работы установленного приложения.
