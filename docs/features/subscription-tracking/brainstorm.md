# Отслеживание подписок

## Problem framing

Kairos не позволял хранить несколько подписок одного сервиса, быстро находить нужный аккаунт перед оплатой, помнить последнюю карту и заранее видеть будущие списания.

## Discovery

1. Пользователь хочет управлять подписками в отдельном окне Kairos.
2. В v1 идентификатор аккаунта копируется вручную из браузера или нативного приложения в clipboard.
3. Совпавшая запись открывается как текущая; неизвестный аккаунт предзаполняет новую запись.
4. Одна карточка соответствует одному сервису и одному аккаунту; одинаковый сервис с разными email — отдельные карточки.
5. Данные и напоминания работают локально, без extension, облака, паролей и номеров карт.
6. Подтверждённые границы: напоминания за 7/3/1 день в 11:00, без «Отложить».
