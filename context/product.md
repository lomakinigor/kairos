# Kairos — Product Context

## Идея
Десктопный виджет-часы для Windows. Два аналоговых циферблата поверх всех окон.
Цель — не дать засидеться за компьютером и поддерживать базовые привычки здоровья.

## Пользователь
Я сам. Работаю долго за компьютером и хочу встроить физическую активность и микро-паузы в рабочий день без волевых усилий.

## Два циферблата
1. **Текущее время** — аналоговый циферблат, местное время
2. **Таймер 45/3** — обратный отсчёт: 45 мин работы → 3 мин перерыва → повтор

## Режимы таймера
- **Работа (45 мин):** тихий обратный отсчёт. Последние 5 мин — прогресс-кольцо желтеет
- **Перерыв (3 мин):** оба циферблата пульсируют янтарным свечением (~1 раз/сек), widget.box-shadow мигает
- По окончании перерыва — автоматически перезапускается 45 мин (никакого нажатия)

## Звук
- "Дин-дон" (два синусоидальных тона, 880 Гц + 660 Гц) — при переходе в перерыв
- Одинарный сигнал (660 Гц) — при переходе обратно в работу
- То же "дин-дон" — при любом напоминании

## Напоминания (встроенные)
- Ежечасно (m=0): "💧 3 глотка воды"
- Ежедневно в 15:00: "Лучшее время для пробежки! 🏃"

## Напоминания (кастомные)
- Хранятся в userData JSON
- Добавляются/удаляются через окно настроек (правый клик → Настройки)

## UX
- Маленький виджет (~270×150px), перетаскивается мышью
- Запускается автоматически со стартом Windows
- Работает только пока включён компьютер (таймер не сохраняется между сессиями)
- Позиция окна сохраняется между сессиями
- Правый клик → контекстное меню: Настройки / Выйти
